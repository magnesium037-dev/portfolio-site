# IBM concept study assets

- `assets/animation/ibm-values.json` is an original 501-frame vector timeline generated by `build_animation.py` for this local design study. It uses eight persistent bars and is not an IBM animation.
- `assets/animation/lottie.min.js` is lottie-web 5.12.1; its MIT license is in `assets/animation/lottie-LICENSE.md`.
- The eight-bar IBM mark is credited to the [Paul Rand archive](https://assets.paulrand.design/Works/IBM/Logos/IBM-8-bar.svg). IBM brand history is linked from the page footer.
- Typography follows [IBM’s type basics](https://www.ibm.com/design/language/typography/type-basics/) and [type scale](https://www.ibm.com/design/language/typography/type-scale/): Plex Sans leads, Plex Mono marks numbers, and headings keep open tracking. The page is an independent exercise, not an IBM template.
- `assets/lab-hero.webp` and `assets/prototype-collaboration.webp` are generated concept images. The latter was made for the scroll-entry photograph and compressed to WebP for this local study.

Open `?motion=1#about` to explicitly preview the animation when the operating system requests reduced motion. Without that opt-in, the desktop page presents all six principles as readable cards.
The six-stage scroll sequence uses Lottie subframes so pointer or wheel input does not snap to integer frames. Technology and Impact illustrations have slow transform-only ambient movement, disabled under Reduced Motion.
